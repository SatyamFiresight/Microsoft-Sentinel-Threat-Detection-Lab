## Tips for Good Screenshots

- Use full browser window, not cropped
- Ensure the Azure portal shows real data (not empty tables)
- Redact any real email addresses or tenant IDs before uploading
- Use browser zoom at 90% for better readability in screenshots
- PNG format preferred over JPEG for UI screenshots
